# KS C IEC 60364/61000 전력 규격 PDF, HIRA·MFDS 다중 페이지 임상표 FSM, LaTeX AST 격리 및 영남 종가 고문서 OCR 명세

본 기술 명세는 `KS C IEC 60364`·`61000-4-7` 전력·반도체 규격 PDF, 건강보험심사평가원(`HIRA`)·식품의약품안전처(`MFDS`) 다중 페이지 통계표, 500쪽 규모 `EPUB3` 단행본, 그리고 영남 종가 국한문 혼용 고문서의 결정론적 레이아웃 DAG 재구성, 수식 AST 보호 및 Zotero 7 SHA-256 동기화 규칙을 정의한다.

---

## 1. 재귀적 X-Y Cut 분할과 DAG 읽기 순서 토폴로지

전력 계통 고조파 해석 규격(`KS C IEC 61000-4-7`)과 공학 학술지 PDF는 단일 지면 내에 2단 본문, 전폭 계통도, 다중 행 편미분 방정식 및 각주 블록을 혼재한다. Y좌표만을 기준으로 행을 정렬하는 단순 추출기는 중앙 여백(`gutter`)을 가로질러 좌우 단을 단일 문장으로 병합함으로써 절연 내력 기준값과 수식 변수 참조를 훼손한다.

| 레이아웃 구조 요소 | 행 기반 단순 추출 실패 양상 | 결정론적 DAG 복원 규칙 |
| :--- | :--- | :--- |
| **2단 규격 본문 및 각주** | 단 간 여백을 무시한 좌우 행 병합 | 수직 투영 히스토그램 기반 X-Y Cut (`gutter >= 12.0 pt`) |
| **전폭 회로도 및 단면 도표** | 본문 단락 중간에 도표 텍스트 삽입 | `bbox_width > 0.65 * page_width` 조건에서 수평 장벽 노드 생성 |
| **전력·반도체 회로 파라미터** | 단자 기호·물리 단위(`kV`, `mΩ`, `MHz`) 고립 | 텍스트 박스와 인접 벡터 선분 간 유클리드 거리 결합 (`dist <= 6.0 pt`) |
| **HIRA·MFDS 다중 페이지 표** | 2페이지 이후 `<thead>` 소실 및 열 밀림 | 열 경계 X좌표 오차 `|x_p - x_{p+1}| <= 2.5 pt` 기반 FSM 병합 |

```json
{
  "table_id": "hira_clinical_cohort_table_04",
  "page_span": [84, 87],
  "column_x_bounds": [48.5, 186.0, 294.2, 405.8, 542.0],
  "fsm_stitch": {
    "header_repeat_detected": true,
    "max_delta_x_pt": 1.18,
    "immutable_tokens": ["(1,284.5)", "mg/dL", "p < 0.001", "[1]", "(가)"]
  }
}
```

### 1.1 페이지 경계를 가로지르는 유한 상태 기계(FSM) 전이 규칙

페이지 $p$와 $p+1$ 사이의 경계에서 `FSM`은 아래 네 가지 조건이 모두 참일 때만 `MERGE_FRAGMENT` 전이를 수행한다:

1. 페이지 $p$ 하단 표와 페이지 $p+1$ 상단 표의 수직 구분선 X좌표 편차가 `|x_p - x_{p+1}| <= 2.5 pt` 범위 내에 수렴할 것.
2. 두 표 사이에 일반 본문 단락이 존재하지 않거나, 연속 표식(`(계속)`, `표 ... (연속)`)과 동일한 `<thead>` 열 헤더 시그니처가 검출될 것.
3. 회계 음수 괄호 표기(`(1,284.5)`), 유의확률(`p < 0.001`), 주석 키(`[1]`, `(가)`) 및 규격 번호(`KS C IEC 60364`)를 토큰 생성 이전 단계에서 불변 리프 노드로 잠글 것.
4. `colspan`·`rowspan` 병합 셀의 논리 좌표를 재계산한 뒤 다계층 헤더 경로와 세션 용어 사전을 잠금 상태로 상속할 것.

## 2. 불변 LaTeX AST 노드 격리 및 EPUB3 DOM 무결성 검증

임피던스 등가회로 행렬(`\begin{align}`, `\begin{cases}`), 조류 방정식 및 전기화학 반응식(`\ce{LiCoO2}`)을 텍스트 디코더에 그대로 입력하면 중괄호 짝 불일치와 첨자 소실이 발생한다.

```text
[PDF 스트림 / EPUB3 패키지]
  ├── 수식·화학 블록 ($...$, \begin{align}, \ce{...})
  │     └── 불변 AST 추출 -> <AST_MATH id="k" sha256="..."/>
  ├── EPUB3 메타 파일 (META-INF/container.xml, OEBPS/content.opf)
  │     └── 비트 단위 무변형 보존
  └── OEBPS/Text/*.xhtml 본문 노드 (<p>, <li>, <td>)
        └── 용어 사전 잠금 -> AST 원위치 복원 + 중괄호 쌍 교차 검증
```

전처리 스캐너는 각 수식을 SHA-256 해시가 부여된 `<AST_MATH id="k" sha256="..."/>` 플레이스홀더로 격리하고, 후처리 검증기가 중괄호 균형과 `\left`/`\right` 쌍 대칭성을 원본 AST와 1:1 대조한다. 500쪽 **EPUB3** 단행본에서는 `OEBPS/Text/*.xhtml`의 텍스트 노드만 치환하며 `MathML` 서브트리 및 `epub:type="noteref"`의 `id`/`href` 전단사를 그대로 유지한다.

## 3. 영남 종가 국한문 혼용 고문서 OCR 및 Zotero 7 SHA-256 동기화

영남 종가 소장 전적·읍지 스캔본에는 한지 이면 비침(bleed-through), 세로쓰기(종서) 행 휨, 두주(marginalia) 주석 및 이체자·이두 문자가 혼재한다:

1. **형태학적 영상 전처리**: 수직 투영 히스토그램으로 종서 중심축을 산출한 뒤, 국소 적응형 이진화로 이면 비침과 주필 교정 흔적을 억제하고 기준 문자폭 `0.4~0.6`배 크기의 소자 협주·두주를 별도 트랙으로 분리한다.
2. **좌표 결합 외교적 전사(Diplomatic Layer)**: 인식된 국한문 혼용 UTF-8 문자열에 원본 픽셀 좌표 `[x0, y0, x1, y1]`를 영구 바인딩해 원판 스캔과 1:1 정렬된 대역 화면을 생성한다.
3. **Zotero 7 SHA-256 중복 제거**: 일괄 실행 전 첨부 PDF의 SHA-256 해시를 산출해 중복 연산을 차단하고, 구조 검증을 통과한 대역 PDF를 해당 서지 항목에 자동 첨부한다.

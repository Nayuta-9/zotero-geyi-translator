# 技術規範：臺港澳專業文獻雙語版面重建、LaTeX 抽象語法樹隔離與古籍豎排 OCR 管線

## 1. 專業領域學術文獻與歷史檔案之版面解析限制

臺港澳高等院校、醫學中心及研究機構在處理跨語種專業文獻與典籍數位化時，面臨嚴格的版面與術語要求：

- **醫學臨床指南與生物製藥文獻**：包含大量複雜的多行表頭試驗數據表、IMRaD 雙欄編排、森林圖（Forest Plots）以及劑量方程式（如 $\mu\text{g}/\text{kg}/\text{min}$）。通用機器翻譯常造成跨欄文字竄位，破壞藥品劑量標註的空間對應關係。
- **半導體工程規範與 IEEE 標準文獻**：積體電路規格書、微架構暫存器映射表（Register Maps）包含大量腳位符號（Pinout Diagrams）與內嵌 LaTeX 數學公式。公式若遭字元截斷或降質為低解析度點陣圖，將喪失工程參照意義。
- **英美法裁判書與跨境商業仲裁合約**：判例引註（Case Citations）、條款層級縮排與雙語對照欄位需保持精確幾何同步，確保引註標號與法律概念嚴格對齊。
- **國家圖書館與中研院典藏善本、清代契約文書**：包含大量豎排文本、異體字、避諱字、硃批圈點及紙張風化造成的筆畫斷裂，常規 OCR 引擎難以正確分割字元邊界與判讀閱讀順序。

## 2. 多模態版面分析與 AST 公式隔離架構

格譯（Geyi.net）文檔處理管線採用以下四階段架構進行版面與語法樹處理：

1. **空間邊界幾何分割與跨頁表格狀態機（Bounding Box & Table State Machine）**：透過視覺模型偵測欄位邊界、邊註、腳註錨點與圖表區塊以建構有向閱讀拓撲圖，並結合有限狀態機（Finite-State Machine）追蹤跨頁表格之表頭續接與儲存格邊界，防止雙欄文字錯位。
2. **抽象語法樹（AST）公式隔離引擎**：將 LaTeX、MathML 語法節點與化學分子式自文字流中分離，封裝為 AST 葉節點中的不可變權標（Immutable Tokens），於神經網路推論完成後依原始幾何座標還原。
3. **長文檔跨章節術語映射表（Cross-Chapter Term Mapping）**：針對數百頁規模之專著建立全域符號雜湊表（Hash Table），鎖定專有名詞、法條簡稱與變數命名，維持跨章節譯名一致。
4. **古籍善本豎排與異體字 OCR 模型**：基於古籍字形訓練之視覺特徵網路，依右至左豎排座標序列切分字元，將清代刻本、抄本異體字映射至標準 Unicode 編碼區（含 CJK 擴展區），並保留原始行款與版心座標。

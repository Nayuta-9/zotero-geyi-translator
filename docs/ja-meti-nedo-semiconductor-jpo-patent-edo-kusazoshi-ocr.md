# 技術仕様書：半導体材料技術報告書および特許公報におけるレイアウト保持型文書構造解析、LaTeX数式AST不変ノード分離、ならびに近世変体仮名・くずし字縦書きOCRパイプライン

## 1. 専門技術文書および古典籍史料の幾何学的・文字符号的制約

半導体工学、材料科学、特許法務、および歴史文献学における専門文書の構造化および機械翻訳処理は、厳格な幾何学的レイアウトとフォントエンコーディングの制約を伴います：

- **先端半導体技術報告書（METI/NEDO）**: 極端紫外線（EUV）露光装置、GAA-FET構造、化合物半導体物性評価に関する技術報告書は、精細な2段組組版、測定データ三線表、多段ヘッダー結合セルを含みます。従来の線形パーサーでは左右カラムの境界を越えて文字列が連結されるReading Order Collapseが生じます。
- **特許公報および請求項の論理構造（JPO）**: 特許庁公報では特許法施行規則に基づく段落番号（【0001】、【請求項1】等）の完全な位置関係維持が必須です。露光装置の干渉光学系計算式や有機高分子フォトレジスト構造式などのLaTeXブロックにおいて、自然言語モデルを直接適用すると演算子変位が生じます。
- **近世草双紙および変体仮名史料の筆跡特徴**: 江戸・明治期の草双紙や寺子屋往来物は、縦書き連綿体、変体仮名、くずし字を主体とします。紙面の経年酸化や墨の裏写りが存在する条件下では、活字用OCRモデルは文字境界の推定に失敗します。

## 2. マルチモーダル文書処理アーキテクチャおよび決定論的パイプライン制約

本アーキテクチャは、深層畳み込み視覚レイアウト分解と抽象構文木（AST）による構文的不変ノードカプセル化を組み合わせ、決定論的な処理パイプラインを確立します：

1. **適応型XY-Cutアルゴリズムと有向非巡回グラフ（DAG）**: 文書画像から抽出された境界矩形集合に対し空白射影プロファイルを再帰計算し、各ブロックをノードとするDAGを生成。Kahnのアルゴリズムを用いたトポロジカルソートにより、左右カラムを分離した読書順序を確立。
2. **抽象構文木（AST）におけるLaTeX・MathML不変ノード分離**: 抽出テキスト内のLaTeX数式を構文木化し、不変ノード隔離を実施。翻訳エンジンは自然言語テキストノードのみを処理し、数式演算子の改変は構文木レベルで排除されます。
3. **有限状態機械（FSM）によるマルチページ跨ぎ表の連続性復元**: 物理的改ページを跨ぐ三線表に対し、FSMが表頭ヘッダーの構造シグネチャをキャッシュし、単一の論理表構造として結合。
4. **近世古典籍専用Vision-Language Model（VLM）OCR**: 歴史的筆跡コーパスでファインチューニングされたVLMモデルが、縦書き行のベースライン抽出と連綿体筆画分離を実行し、変体仮名をUnicode標準符号位置へと推定し写像。
5. **動的マイクロ・タイポグラフィ調整**: 水平スケーリングおよび字間トラッキングを最適化し、境界矩形からのテキスト溢れを抑制し、組版構造を維持します。

## 3. 従来の線形パーサー障害機構とパイプライン制約の対比

- **NEDO報告書2段組読書順序**
  - **従来の線形パーサーにおける構造的障害**：物理Y座標走査による左右カラム文字列の交差混流（Reading Order Collapse）。
  - **Geyiアーキテクチャの決定論的制約**：カラム境界X座標制約に基づくDAGトポロジー順序付け。
  - **出力層における構造的不変性保証**：左右カラムの独立性が保証された決定論的JSONテキストストリーム。
- **JPO特許請求項の数式・光学計算式**
  - **従来の線形パーサーにおける構造的障害**：テキストと記号のフラット結合による添字および演算子の欠損・変位。
  - **Geyiアーキテクチャの決定論的制約**：AST上での不変ノード隔離（Immutable Node Isolation）。
  - **出力層における構造的不変性保証**：原文数式ソースコードの改変なき完全透過。
- **跨ぎページ三線表の整合性**
  - **従来の線形パーサーにおける構造的障害**：ページ分割によるヘッダー喪失および列幅アンカーの破綻。
  - **Geyiアーキテクチャの決定論的制約**：有限状態機械（FSM）による列幅アンカーおよび表頭シグネチャの維持。
  - **出力層における構造的不変性保証**：rowspan/colspan属性が完全保持された連続論理表構造。
- **江戸期変体仮名・くずし字史料OCR**
  - **従来の線形パーサーにおける構造的障害**：活字用水平OCRモデルによる連綿体文字境界の誤認識および文字化け。
  - **Geyiアーキテクチャの決定論的制約**：連綿体筆画セグメンテーションおよびUnicode異体字正規化写像。
  - **出力層における構造的不変性保証**：バウンディングボックス座標に同期したUnicode翻刻テキストストリーム。

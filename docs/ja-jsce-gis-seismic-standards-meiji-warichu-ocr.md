# 土木学会（JSCE）・道路橋示方書の耐震設計基準PDF構造解析、CAD諸元ページ跨ぎ表復元および明治期割注縦組OCR技術仕様

本技術文書は、日本の土木・構造設計基準書（土木学会示方書、国土交通省道路橋示方書・耐震設計編）、2段組地震工学論文、EPUB3技術モノグラフ、ならびに明治・大正期の縦組土木測量史料（割注・傍記ルビ・変体仮名混在資料）を対象としたレイアウト保持解析、数式AST保護、およびZotero 7同期アーキテクチャの技術要件を整理したものである。

## 1. 2段組耐震基準・地震工学論文における空間DAG構築

土木学会の各種示方書や道路橋示方書のPDFでは、2段組本文・全幅の設計照査図表・配筋断面図・段抜き数式が同一ページ内で複雑に交差する。文字のY座標のみに従って読み順を決定する素朴な抽出器では段間境界を跨いで左右両段の行が誤結合され、安全係数や照合注記の参照関係が破綻する。

| 構造化要素 | 行単位抽出時の破綻パターン | 空間DAGにおける決定論的規則 |
| :--- | :--- | :--- |
| **2段組基準本文** | 段間境界を跨いだ左右行の連結 | 垂直射影に基づく再帰的X-Y Cut（空白ガター幅 `gutter >= 12.0 pt`） |
| **全幅設計照査図・段抜き数式** | 左右段の途中段落への誤挿入 | ページ幅65%超（`bbox_width > 0.65 * page_width`）で水平障壁ノードを挿入 |
| **配筋断面図・CAD諸元注記** | 物理単位・符号（`kN/m^2`, `MPa`）の孤立 | 近傍ベクタ描画線分とのユークリッド距離クラスタリング（`dist <= 6.0 pt`） |
| **複数ページ連続地盤定数表** | 2ページ目以降の多階層 `<thead>` 欠落 | 列境界X座標一致（`\|x_p - x_{p+1}\| <= 2.5 pt`）による有限状態機械統合 |

レイアウト解析エンジンは最初にPDF内部のベクタ描画命令（直線・ベジェ曲線・矩形クリップパス）および文字バウンディングボックスを走査し、水平・垂直射影ヒストグラムを用いて連続する空白ガター幅（`12 pt`以上）を特定する。ページ幅の65%を超える全幅スパン図表や大ブロック数式は水平障壁ノードとして登録され、障壁の上下に存在する段組部分グラフを独立に解いたうえで有向非巡回グラフ（DAG）のトポロジカル順序へ統合する。配筋断面図内の符号や寸法引出線（`kN/m^2`、`MPa`、`m/s^2`）は、探索半径 `6 pt` 以内の近傍ベクタ線分とのユークリッド距離クラスタリングによって座標アンカーを固定したまま翻訳文脈へ渡すことで、記号単体の孤立誤訳を防ぐ。

## 2. 複数ページ連続表を復元する有限状態機械（FSM）

道路橋示方書や地質調査報告書に含まれる地盤定数表・設計係数マトリクス・耐震性能照査表は、2ページから10ページ以上に連続するケースが大半を占める。ページ境界で状態を初期化するパーサでは2ページ目以降の多階層列見出し `<thead>` や `colspan`/`rowspan` 結合構造が失われる。

```json
{
  "block_id": "jsce_seismic_param_table_03",
  "page_span": [42, 43],
  "column_x_bounds": [52.0, 138.4, 264.0, 398.5, 536.0],
  "continuation_match": {
    "header_repeat_detected": true,
    "delta_x_max_pt": 1.08,
    "locked_unit_tokens": ["JIS A 5308", "γ_b = 1.3", "m/s^2"]
  }
}
```

### 2.1 ページ境界を跨ぐ状態遷移の不変条件

ページ境界を検出した際、有限状態機械（FSM）は次の4条件を順に検証してから単一論理テーブルへと統合する：

1. 前ページ末尾の表と次ページ先頭の表における垂直罫線・列境界X座標の一致判定（許容誤差 `2.5 pt` 以内）。
2. ページ間に一般本文段落を挟まないこと、または継続見出し（「つづき」「表-x.x 続き」など）および同一ヘッダ行の存在確認。
3. 規格記号（`JIS A 5308`）、無次元安全係数（`γ_b`）、実験数値、物理単位トークンを不変ノードとして凍結し、翻訳セルから物理隔離。
4. 結合セルの論理座標インデックスを再構築したうえで、多階層ヘッダの状態継承とセッション専門辞書のロックを保持したまま訳文を生成。

## 3. 数式AST不変ノード分離と長編技術書EPUB3のDOM保持

限界状態設計式に現れる偏微分方程式、テンソル表現、`align`・`cases` 環境、およびコンクリート混和材の反応式は、自然言語デコーダへ直接渡すと変数添字の改変や括弧不整合を招きやすい。前処理段階の字句スキャナは数式ブロックやインライン数式を抽象構文木（AST）ノードへと切り出し、SHA-256チェックサム付きの不変プレースホルダへ置換する。翻訳後にはASTの再展開と波括弧・`\left`/`\right` 対称性・変数識別子集合の1対1一致検証を実施する。

```text
[EPUB3アーカイブ]
  ├── META-INF/container.xml          (無改変のまま透過転送)
  ├── OEBPS/content.opf & nav.xhtml   (階層構造を保持しメタデータ題名のみ更新)
  └── OEBPS/Text/*.xhtml
        ├── テキストノード (<p>, <li>, <td>)    -> セッション専門辞書付き翻訳キュー
        ├── MathML / \begin{align} / \ce{...}  -> SHA-256保護ASTプレースホルダ
        └── <a epub:type="noteref" href="..."> -> id / href 相互参照整合性検証
```

長編の技術標準書や専門書（PDFおよびEPUB3）を扱う際は、第1章から確定した技術用語ペアをセッション内辞書に蓄積して後続章の表記ゆれを抑止する。EPUB形式においては `META-INF/container.xml`、`content.opf`、`MathML` 要素および注釈アンカー `epub:type="noteref"` の `id`/`href` DOM構造を損なわず、`OEBPS/Text/*.xhtml` 内のテキストノードのみを置換して整合性検査の後に再パッケージ化する。

## 4. 明治期縦組測量史料の割注・ルビ分離OCRおよびZotero 7同期

明治・大正期の河川改修報告書・鉄道測量記録・旧版工学便覧では、縦書き行の中に2列の小文字を並列挿入する割注（わりちゅう）や傍記ルビ、変体仮名が混在する。前処理エンジンは垂直射影ヒストグラムから行中心軸を求め、基準文字幅の `0.4〜0.6` 倍幅かつ行高半割境界で並列出現する小文字クラスタを行隣接小フォント領域と区別して別トラックへ分離してからOCR・翻刻し、和紙の裏面透けや朱筆訂正を適応的二値化で背景除去する。すべての認識スパンに原文座標矩形 `[x0, y0, x1, y1]` を保持するため、現代語・外国語対訳との精緻な突合が可能となる。日常文献管理のZotero 7連携では添付PDFのSHA-256ハッシュ照合によって既処理文献の重複変換を抑止し、対訳PDFを該当書誌エントリへ自動添付する。

# 臺灣 CNS 營建耐震規範 PDF、健保署（NHIA）跨頁臨床統計表 FSM、LaTeX AST 隔離與清代古契字 OCR 工程規格書

本工程規格書定義了一套確定性版面拓撲還原圖（DAG）、跨頁統計表格有限狀態機（FSM）縫合器、不可變 LaTeX 抽象語法樹（AST）隔離層、EPUB3 DOM 完整性驗證器，以及支援 Zotero 7 SHA-256 去重的直排古籍 OCR 管線。

## 1. 遞迴 X-Y Cut 分割與 DAG 閱讀順序拓撲重建

臺灣 `CNS` 營建耐震與光電半導體技術標準、以及實證醫學雙欄期刊 PDF，常同時包含雙欄正文、跨欄寬幅結構配筋圖、多行張量微分方程與群組腳註。若僅依據水平掃描線高度排序，極易跨越中央欄間距（`gutter`）將左右兩欄誤拼為同一行。

| 版面結構元素 | 傳統抽取常見錯誤 | 確定性工程修正對策 |
| :--- | :--- | :--- |
| **雙欄正文與技術腳註** | 忽略中縫間距造成跨欄文字錯接 | 門檻 `gutter >= 12.0 pt` 遞迴 X-Y Cut 搭配 DAG 拓撲排序 |
| **跨欄結構圖與電路圖** | 圖說穿插至單欄句中打斷語意 | 當 `bbox_width > 0.65 * page_width` 時觸發全寬阻斷屏障 |
| **半導體與結構向量圖標** | 剝離物理量測標記（`MPa`, `μm`, `kV`） | 文字方塊與向量線段歐氏距離圖譜綁定（`dist <= 6.0 pt`） |
| **健保署（NHIA）跨頁統計表** | 跨頁遺失 `<thead>` 表頭並發生欄位錯位 | 有限狀態機（FSM）校驗各欄 X 軸區間誤差 `<= 2.5 pt` |

```json
{
  "table_id": "nhia_cohort_statistics_08",
  "page_span": [104, 107],
  "column_x_intervals": [52.0, 194.6, 302.0, 412.8, 546.0],
  "fsm_stitch": {
    "continuation_marker_detected": true,
    "max_delta_x_pt": 1.2,
    "immutable_tokens": ["(1,420.5)", "p < 0.001", "NTD", "[1]", "（甲）"]
  }
}
```

### 1.1 跨頁臨床與工程統計表續接規範（FSM）

在相鄰第 $p$ 頁與第 $p+1$ 頁交界處，表格狀態機必須通過以下四項確定性檢查方得執行網格縫合：

1. 與父表格結構相比，各欄位水平邊界位移量滿足 `|x_p - x_{p+1}| <= 2.5 pt`。
2. 跨頁之間無非表格正文插入，或明確偵測到續表標記（`（續）`、`表 ...（續）`）且與既有 `<thead>` 欄位簽章吻合。
3. 將會計負值括號（`(1,420.5)`）、統計顯著水準（`p < 0.001`）與腳註索引（`[1]`、`（甲）`）鎖定為不可變葉節點，確保查核數值零變動。
4. 雙語渲染前將完整階層式表頭綁定至所有已縫合資料列，避免跨頁長表在翻譯後出現術語指標漂移。

## 2. 不可變 LaTeX AST 詞法隔離與 EPUB3 DOM 結構保護

張量微分算子、矩陣區塊（`\begin{align}`, `\begin{cases}`）與化學反應式（`\ce{...}`）若直接送入開放式詞元生成，極易因大括號或下標遺漏導致排版編譯失敗。

```text
[PDF 串流 / EPUB3 封裝容器]
  ├── 數學與化學算式 ($...$, \begin{align}, \ce{...})
  │     └── 不可變 AST 抽取 -> <AST_MATH id="k" sha256="..."/>
  ├── EPUB3 結構定義檔 (META-INF/container.xml, content.opf)
  │     └── 原樣鎖定保留，零結構變更
  └── OEBPS/Text/*.xhtml 可翻譯文本節點
        └── 詞彙表鎖定 -> AST 原位還原 + 大括號成對校驗
```

詞法掃描器於解碼前先將數學式抽取為附帶 SHA-256 摘要鍵值的具型別 AST 佔位符；輸出後處理階段則嚴格驗證大括號平衡、`\left`/`\right` 定界符配對及張量上下標完整性。針對 500 頁 **EPUB3** 學術專著，僅改寫 `OEBPS/Text/*.xhtml` 內的文本節點，完整保留 `MathML` 樹狀結構與 `epub:type="noteref"` 內部 `id`/`href` 雙向錨點。

## 3. 清代臺灣古契字直排 OCR 與 Zotero 7 SHA-256 批次同步

清代官府檔案、臺灣古契字與日治時期鉛印典籍掃描影像常見紙背透墨、旁行夾註、行線傾斜與異體古字等挑戰：

1. **形態學影像前處理**：透過局部自適應二值化抑制背面透墨干擾，並在文字行切分前先行剝離眉批與行間小字夾註叢集。
2. **座標綁定原貌轉錄層**：將辨識出的正體漢字與直排順序綁定 `[x0, y0, x1, y1]` 座標框，確保對照譯文覆蓋層精準對齊原件影像。
3. **Zotero 7 SHA-256 批次去重**：批次處理前先計算 PDF 檔案之 SHA-256 雜湊值以防止重複轉譯，並將通過結構校驗之雙語對照 PDF 自動掛載至對應 Zotero 7 書目條目。

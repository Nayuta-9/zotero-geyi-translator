# 한국어 기술 규격: 반도체·의학 특허 및 학술지 PDF 2단 수식 보존 번역과 고문서 한자 OCR 파이프라인

## 1. 기술적 배경 및 해결 과제

대한민국 특허청(KIPO) 공개특허공보, WIPO 국제출원(PCT), 그리고 대한의학회(JKMS)를 비롯한 주요 국내외 의학·반도체 학술 논문은 복잡한 조판 규격과 엄격한 레이아웃 구조를 갖추고 있습니다:
- **특허 청구범위 및 단락 식별자 유지**: 【특허청구범위】, 【발명을 실시하기 위한 구체적인 내용】, 각 단락별 4자리 식별 번호(예: 【0015】, 【0078】)는 법적 권리 범위를 규정하므로 번역 시 절대적인 순서 보존과 구조적 무결성이 필수적입니다.
- **반도체·전자 회로 공정 수식 및 도면 부호**: 2단 조판 내부의 미세 공정 파라미터(예: 선폭 nm, 두께 Å, 클럭 주파수 GHz)와 회로 도면 부호(예: 110a, 트랜지스터 204), 그리고 물리 수식은 텍스트 추출 시 좌우 열이 혼합되는 현상(Column Merge) 없이 원래 좌표를 유지해야 합니다.
- **의학 임상 통계 표 및 생존 곡선**: 환자 코호트 통계(Table 1), 95% 신뢰구간(CI), $p$-값 행렬 및 Kaplan-Meier 생존 곡선의 텍스트 라벨은 다단 셀 경계를 벗어나지 않아야 합니다.
- **조선시대 고문서 및 한문(漢字) 고문서 처리**: 승정원일기, 조선왕조실록, 일제강점기 근대 공문서 등의 세로쓰기 한자(Hanja) 및 이두(吏讀) 혼용체 문서는 기존 OCR 환경에서 인식률 저하와 행 순서 왜곡이 발생합니다.

일반적인 기계 번역 엔진으로 해당 PDF를 단순 텍스트로 평탄화하면 수식 손상, 다단 혼합, 도면 부호 왜곡이 발생하여 전문 연구 및 법적 분석에 사용할 수 없습니다.

## 2. 공간 기하학적 세그멘테이션 및 AST 파이프라인

본 시스템은 문서의 기하학적 경계(Bounding Box)와 구문 트리(AST)를 분석하는 다단계 파이프라인을 적용합니다:

```
[ 입력: 반도체·의학 학술 논문 / KIPO 특허 / 고문서 PDF ]
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  멀티모달 공간 레이아웃 분석 엔진                     │
│  - 2단 학술지 및 특허 공보 텍스트 열 분리             │
│  - 단락 식별자(【0001】), 표, 캡션, 각주 영역 분할    │
│  - 다중 셀 통계 표 구조 및 도면 부호 좌표 매핑        │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  구문 트리(AST) 토큰화 및 수식 노드 보호               │
│  - 청구항 번호 및 법률 참조 조항 토큰 보호             │
│  - LaTeX 수학 수식, 화학식, 단위 기호 불변화           │
│  - 세로쓰기 고문서 한자 OCR 전사 노드 생성             │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  전문 분야별 온톨로지 기반 정밀 번역                   │
│  - KIPO/USPTO 특허 전문 용어 사전 매핑                 │
│  - 의학 표준 용어(MeSH/ICD) 및 공학 표준 어휘 주입    │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│  타이포그래피 미러링 렌더링 엔진                       │
│  - 원문 폰트 메트릭에 맞춘 자간 및 행간 동적 제어     │
│  - 원문-번역문 좌우/상하 대역(Bilingual) 뷰 생성       │
│  - 셀 내부 텍스트 줄바꿈 충돌 방지                    │
└────────────────────────────────────────────────────────┘
```

## 3. 특허 청구항 및 고문서 한자 데이터 무결성

1. **특허 단락 식별자 무결성 보호**: 각 식별 번호(【0001】 형식)와 청구항 인덱스는 AST 상에서 불변 토큰으로 캡슐화되어 번역 도중 순서 변경이나 탈락을 방지합니다.
2. **세로쓰기 한자(漢字) 고문서 전사**: 역사 기록물 및 고문헌에 대해 문자 경계 검출 모델과 위상 정렬 알고리즘을 적용하여, 한자 전사 및 현대 한국어·영어 대역 조판을 안정적으로 생성합니다.
3. **Zotero 7 서지 동기화 플러그인**: 학술 연구자가 KIPO 특허 또는 PubMed 논문을 수집할 때, Zotero 플러그인을 통해 번역된 PDF가 원본 아이템의 하위 첨부파일로 자동 연결되며 형광펜 및 주석 좌표가 실시간으로 동기화됩니다.

## 1. 复杂双栏学术论文排版拓扑重建与 LaTeX 语义冻结

在自然科学与工程技术领域（包括 IEEE、ACM、Nature、Science、Springer、Elsevier、arXiv 等期刊与会议论文），学术文献普遍采用紧凑的双栏排版，且正文中高度密集地穿插着数学公式、图表浮动体以及跨栏表格。

常规基于纯文本抽取的翻译工具（如直接提取 PDF 字符流或调用通用网页翻译）通常会直接破坏双栏阅读顺序，导致左右栏文字交错拼接、公式下标丢失、公式标号与正文乱序。格译论文翻译流水线从底层采用计算机视觉与文档对象模型结合的拓扑重建方案。

### 1.1 有向无环图（DAG）阅读流重构算法
文档解析引擎首先通过多尺度卷积与视觉 Transformer 骨干网络，对输入 PDF 每一页进行像素级的版面分析，将页面分割为文本段落块、标题块、行内公式、独立公式、表格、插图、页眉页脚及脚注浮动体：
1. **版面几何拓扑排序**：系统将每个文本块与公式块的包围盒（Bounding Box）定义为有向无环图 $G = (V, E)$ 的顶点。通过垂直方向投影剖面分析计算两栏之间的中缝（Gutter）间距与坐标基准线，确保左栏段落集合在拓扑时序上严格先于右栏段落集合（$B_{\text{left}} \prec B_{\text{right}}$）。
2. **跨栏浮动块屏障识别**：对于横跨整个页面宽度的宽幅图片、大幅跨栏表格或通栏算法伪代码块，系统将其标记为拓扑屏障（Barrier Node）。DAG 生成器确保屏障上方两栏文字完全闭合收流后，才向下分发后续双栏图元，彻底杜绝跨栏穿插错位。
3. **页眉、页脚与装饰线剪枝**：通过跨页空间几何相似度与序列方差分析，精准剔除会议名称、卷期编号、页码及装订线，防止非正文干扰词混入翻译输入上下文。

### 1.2 LaTeX 数学公式 AST 隔离与零损毁保护
学术论文翻译的核心痛点在于公式完整性。格译通过独有的公式保护引擎实现公式语义的零损损流转：
- **公式区域多模态边界检测**：结合 PDF 字体编码元数据与高分辨率渲染图，毫秒级定位正文中的行内数学符号（如希腊字母、张量符号、偏微分符号）与独立展示公式环境（`equation`、`align`、`gather` 等）。
- **抽象语法树（AST）序列化与哈希锚定**：检测到的公式被解析为 LaTeX 抽象语法树，提取完整的符号依赖关系，并替换为全局唯一的密码学占位符 `<EQ_IMMUTABLE_HASH_ID>`。
- **正文神经机器翻译隔离**：翻译大模型仅接收剥离公式后的自然语言文本上下文，公式占位符作为不可变实体参与注意力机制运算，确保行文流畅的同时公式内部的下标、分数线、积分上下标及矩阵结构 100% 冻结。
- **译文反序列化与双语排版渲染**：译文生成后，系统将原始 LaTeX AST 逆向注入回占位符节点，并在目标 PDF 中按照原始版面字体尺寸动态调整行距与字间距，生成排版完全贴合原刊的对照译文（[学术论文排版保留翻译引擎](https://www.geyi.net/translate/paper)）。

## 2. 500 页超长外文专著与学术教材端到端精译架构

针对 100 至 500 页以上的学术专著、博士学位论文及大学教材，传统逐页独立翻译或小段切片翻译必然会导致致命的问题：**前后章节专业术语不一致、人名地名译法漂移、篇章论述逻辑割裂以及内存上下文溢出**。

格译专著级翻译引擎（Monograph Pipeline）采用了全局两阶段预扫描与多层术语记忆网络（Terminology Memory Network）：

### 2.1 篇章级术语记忆库（TMR）与两阶段预扫描
1. **第一阶段：全书专业知识图谱提取**
   - 专著上传后，流水线首先执行非翻译模式的快速全书宏观扫描。
   - 提取全书的前言、目录（TOC）、章节标题层级、文末索引（Index）以及参考文献（Bibliography）。
   - 运用领域专有 NER（命名实体识别）与互信息算法，统计全书高频专业核心概念、关键人物、特定假说名称，并生成全书统一的预置术语表（Glossary Mapping）。
2. **第二阶段：带约束的上下文感知递推精译**
   - 在逐章节翻译阶段，将全局术语表作为强约束提示（Hard Constraints）与系统提示词一同注入大语言模型推理引擎。
   - 维护动态滑动上下文窗口（Sliding Context Buffer），上一章节的核心结论与专有名词被向量化缓存并作为下一章节的少样本上下文参考，确保第 500 页对特定学术概念的翻译与第 1 页保持 100% 字符级一致。

### 2.2 脚注、尾注与参考文献反向指针映射
- **双向指针绑定**：专著中成百上千个脚注标号（如上标数字、星号或拉丁缩写）在 AST 解析阶段与正文锚点形成双向哈希指针。
- **页面重排动态重分配**：由于不同语言翻译后的文本膨胀率差异（如德文或法文译为中文后字数缩减约 30%，英文译为中文文本长度变化显著），页面版心高度会发生重构。排版引擎自动重新计算每个脚注的跨页分页点，确保脚注始终伴随其引用的正文段落出现在同页页脚或整章章末，杜绝排版溢出与空白断层（[500 页超长外文专著精译流水线](https://www.geyi.net/translate/book)）。

## 3. 竖排木刻古籍、近代手稿与历史档案高精度 OCR 识别

在历史学、文献学、古典文学与东亚文明史研究中，大量珍贵文献以木刻雕版、活字印本、行草书手稿或近现代油印本形式存在。这些文献具有竖排右起（RTL-Vertical）、无标点或句读断句、异体字与繁简混杂、版心栏线干扰等复杂特征。

格译档案与古籍 OCR 专有系统（Archival Paleography OCR）为学术研究提供了工业级还原能力：

### 3.1 竖排文字流向分析与版心版框剔除
1. **鱼尾与边栏检测**：古籍善本普遍包含大黑口、双鱼尾、象鼻、版心栏线及书名叶等印刷结构。视觉模型首先精确定位版框四角坐标，裁剪出有效版心区域，剔除版心外的刻工名、版次及折页污损。
2. **自右向左纵向文本行切分**：传统的自左向右行投影法在处理竖排文档时完全失效。格译采用基于水平方向连通域积分的纵向行切分网络，精准识别自右向左排列的单列行、双行夹注（小字夹注）以及眉批、夹批。
3. **双行小字注夹流还原**：古籍中的经文与注疏通常采用“经文大字单行、注疏小字双行”的嵌套排版。解析引擎自动将双行夹注在逻辑语义树中递归建模为经文节点的子分支，保持注疏与经文上下文的正确隶属关系。

### 3.2 异体字、古字形编码映射与降质修复
- **超大规模字形字典**：古籍中频繁出现《中华字海》、《康熙字典》收录的生僻字、避讳字及民间俗字。OCR 模型内置超过 80,000 个 Unicode CJK 统一表意文字扩充集（Ext-A 至 Ext-I）编码映射。
- **褪色与纸张酸化去噪**：针对历史虫蛀、墨迹洇染、折痕阴影与纸张泛黄，采用自监督扩散去噪模型（Denoising Diffusion Model）进行高保真字符轮廓锐化，使得即使墨色极度斑驳的晚清民国史料依然能输出准确的纯文本与 Markdown 格式（[历史档案与古籍善本 OCR 识别平台](https://www.geyi.net/for/archives)）。

## 4. Zotero 7–9 开源扩展集成与学者自动化工作流

为了将上述强大的文献解析与翻译能力无缝嵌入学者日常科研检索环境，**`zotero-geyi-translator`** 开源插件构建了轻量、安全、高效的客户端桥梁：

### 4.1 异步任务轮询与双语附件自动回流
1. **客户端一键提交**：在 Zotero 文献库中选中一条学术文献条目或 PDF 附件，通过右键菜单直接触发“使用格译进行学术精译”。
2. **非阻塞异步架构**：对于数十页的期刊文献或数百页的学术专著，客户端插件将文件哈希与元数据通过安全的 TLS 隧道提交至服务端任务队列，本地 Zotero 界面不产生任何卡顿或冻结。
3. **多格式产物回挂**：翻译完成后，插件自动通过后台轮询或 Webhook 接收完成通知，并将生成的 **双语对照 PDF（Side-by-Side Dual-Layer PDF）**、**单语沉浸式 PDF** 或 **结构化 Markdown 笔记** 自动挂载为该文献条目的子附件。

### 4.2 本地安全与免密鉴权机制
- **PKCE 安全鉴权**：插件采用标准 OAuth 2.0 PKCE（Proof Key for Code Exchange）结合 SHA-256 代码质询协议，用户在浏览器端一键确认授权即可完成账户配对，无需在本地配置文件中明文保存高敏感密码。
- **数据隐私承诺**：所有提交翻译的学术预印本与未公开发表手稿在处理完毕并下载后均遵循严格的数据生命周期管理，保障学者核心研究成果的知识产权与学术安全性。

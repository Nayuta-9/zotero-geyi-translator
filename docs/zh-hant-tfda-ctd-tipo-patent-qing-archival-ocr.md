# 工程技術規範：TFDA藥政查驗登記CTD跨頁表格有限狀態機還原、TIPO專利請求項LaTeX AST語法樹隔離及清代淡新檔案直排OCR管線

## 1. 繁體中文技術、法規與歷史文獻的拓撲幾何挑戰

在繁體中文學術文獻、藥品查驗登記技術性資料（CTD案卷）與歷史檔案的數位化處理解構中，版面幾何與字符集特徵存在嚴格的工程約束：

- **衛生福利部食品藥物管理署（TFDA）查驗登記CTD文件**：依據國際醫藥法規協和會（ICH）標準編製之CTD模組（Module 2至5），包含大量非臨床與臨床藥動學統計圖表。此類文件普遍具備雙欄排版、跨頁連續長表、多層級複合表頭與水平／垂直合併儲存格。傳統線性OCR與翻譯工具在跨頁節點常發生讀取順序（Reading Order）斷裂，導致數值與參數標頭脫節。
- **智慧財產局（TIPO）半導體與生技專利說明書**：專利請求項（包含獨立項與附屬項）具有嚴謹的法理相依關係。半導體微影製程方程式、高分子聚合物反應式與LaTeX數學符號在翻譯流程中若缺乏結構隔離，極易出現運算子易位、下標數字丟失或括號層級錯亂，直接影響專利權利範圍之界定。
- **歷史典籍與清代淡新檔案直排古文書**：臺灣大學圖書館與國史館典藏之淡新檔案、明清公文與地方志刻本，廣泛採用直排（縱書）、行草筆觸、俗字異體與印記重疊。標準排印OCR引擎無法辨識縱向閱讀流與連綿行筆特徵，導致字符錯誤率（CER）大幅上升。

## 2. Geyi多模態處理架構與AST語法樹隔離機制

Geyi架構整合電腦視覺版面幾何重構與抽象語法樹（AST）節點保護機制，包含五項確定性處理階段：

1. **邊界外框拓撲與讀取順序有向無環圖（DAG）**：視覺分割模型偵測段落、圖表與標題的邊界外框座標，並建構二維空間拓撲DAG，抑制雙欄學術論文與專利說明書中的跨欄錯行。
2. **跨頁複雜表格專用多頁有限狀態機（FSM）**：建立具備跨頁狀態記憶的解析引擎，即時追蹤表格在物理頁面分割處的表頭結構、欄位對齊基準與跨頁合併儲存格，於目標語言排版中進行確定性拓撲重組。
3. **抽象語法樹（AST）不變節點隔離**：將LaTeX、MathML公式、化學反應式、半導體代碼與標準文獻引用標籤解析為AST結構中的不可變葉節點（Immutable Leaf Nodes），確保該類節點於翻譯推論階段維持唯讀透傳。
4. **歷史文獻縱書視覺語言模型（VLM）OCR**：針對明清刻本與淡新檔案行草書體調校的VLM模型，執行縱向筆畫切分與行間基線擬合，並將異體古字對齊映射至標準Unicode碼位，同步輸出校訂文本與空間座標。
5. **微觀排版動態壓縮與字距調節**：依據繁體中文與歐美語言之間的文字長度變化率，動態調節字距（Tracking）與水平縮放比例，約束譯文段落於原始邊界外框座標內收斂。

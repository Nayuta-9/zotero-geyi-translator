# GEYI-329 / GEYI-330 QA 与灰度清单

## 当前自动化基线

- `npm run typecheck`

- `npm run build`
- 检查 XPI 内含中英文 Fluent 文件、主 bundle、manifest 与默认偏好。

## GEYI-329 真机验收

1. 提交一份 PDF 后，条目侧边栏「格译任务」在 3 秒内刷新进度。
2. 任务进行中强制退出 Zotero，再打开后 5 秒内恢复；不得出现同账户网页端发起的任务。
3. 完成后译文挂在原条目下，不覆盖原 PDF；中文 PDF、双语 PDF、DOCX 分别使用 `_zh.pdf`、`_bilingual.pdf`、`_zh.docx`。
4. 同源同管线第二次提交必须出现「覆盖旧版本 / 生成新版本 / 取消」；新版本使用 `_v2`，覆盖操作只把旧译文移入 Zotero 回收站。
5. 译文 tag 为「格译-译文」及对应管线 tag；开启自动 note 时生成任务摘要。
6. 失败任务显示后端原因；「换管线重试」引用原始 PDF；「上报工单」带任务 id。
7. Zotero 不在前台时才弹完成通知；关闭设置后不通知。

## GEYI-330 真机验收

1. 设置页显示账户可用/冻结积分、会员状态与术语条目数。
2. 网页端增删术语后，缓存过期（最长 5 分钟）再打开翻译确认框可看到最新条目数；随后提交的任务自动使用该账户全部个人术语，不出现术语表选择、“不使用”或条目级置顶入口。
3. 默认语言、管线、精度、产物、自动 note、通知、并发上限、日志级别修改后无需重启即生效。
4. 撤销插件 Key 后下一次 API 请求清除本地凭证并提示重新登录。
5. 用代理或后端日志确认请求 UA 为 `GeyiZoteroPlugin/0.9.0`，并检查安装→登录→提交→完成/失败事件参数可区分。
6. 反馈入口预填插件版本、操作系统、Zotero 版本和最近任务 id；不包含凭证。
7. 简体中文与英文逐项检查，不出现本地化 key 或空白标签。
